# Bilibili视频下载器 Chrome插件

一个专为Bilibili设计的Chrome浏览器扩展，支持下载视频和音频。

## ✨ 功能特性

- 🎬 支持多种视频清晰度下载（360P-4K）
- 🎵 支持单独下载音频文件
- 🚀 自动识别视频信息
- 💡 简洁直观的用户界面
- 🔧 无需额外软件，浏览器原生下载

## 📦 安装方法

### 开发者模式安装（推荐）

克隆本仓库后直接加载，无需任何额外准备：

```bash
git clone https://github.com/castorhrio/bilibili-downloader.git
```

1. 打开 Chrome，输入 `chrome://extensions/` 进入扩展管理页面
2. 开启右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择刚才 clone 出来的 `bilibili-downloader` 文件夹
5. 安装完成，工具栏会出现扩展图标

## 🚀 使用方法

1. **打开Bilibili视频页面**
   - 前往 [bilibili.com](https://www.bilibili.com)
   - 打开任意视频页面

2. **开始下载**
   - 在视频页面找到蓝色的"下载"按钮（通常在视频标题附近）
   - 点击下载按钮打开下载面板
   - 选择所需的视频质量或音频选项
   - 点击对应的下载按钮

3. **查看下载**
   - 下载会自动开始
   - 可在浏览器底部的下载栏查看进度
   - 下载完成后会收到通知

## 🔧 技术说明

### 工作原理
- 通过内容脚本注入到Bilibili页面
- 拦截和解析视频API响应
- 提取DASH格式的视频/音频流地址
- 使用Chrome下载API进行文件下载

### 文件结构
```
bilibili-downloader/
├── manifest.json          # 插件配置（Manifest V3）
├── content.js             # 内容脚本：拦截并解析视频流信息
├── injected.js            # 注入页面脚本：插入下载按钮
├── background.js          # 后台服务脚本
├── popup.html             # 弹出窗口页面
├── styles.css             # 样式文件
└── README.md
```

## 🐛 故障排除

### 常见问题

**Q: 找不到下载按钮？**
A: 
- 确保在Bilibili视频页面
- 刷新页面重试
- 检查插件是否正确安装

**Q: 下载失败？**
A: 
- 检查网络连接
- 尝试其他视频质量
- 查看浏览器下载设置

**Q: 视频无声音？**
A: 
- 现代视频格式采用分离的音视频流
- 需要专业软件合并音视频（如FFmpeg）
- 或直接下载音频文件

### 调试方法
1. 按F12打开开发者工具
2. 查看Console标签页的错误信息
3. 在Extensions页面查看插件状态
